# sample-data

Synthetic **Norwegian (Bokmål)** sample documents for the "HSO AI Assistant"
demo scenario. These are entirely fictional — no real personal or health data.

Seven documents (PDF/DOCX/XLSX/MD) are added here in Phase 7 to seed the demo:
a system description, a data-processing agreement, a supplier security
questionnaire, a processing-record excerpt, etc.

> Do **not** place real municipal data here. The pre-commit hook and CI scan
> will flag anything that looks like a real fødselsnummer or API key.
