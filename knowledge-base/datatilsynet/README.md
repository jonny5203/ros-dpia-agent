# Datatilsynet (Norwegian Data Protection Authority)

The DPIA screening tool is a deterministic rules engine over the **9 WP29/EDPB
screening criteria** (WP248 rev.01), rendered in Norwegian on `datatilsynet.no`.

- **Criteria (9):** evaluation/scoring · automated decisions with legal/similar
  effect · systematic monitoring · special categories / highly personal data ·
  large-scale processing · matching/combining datasets · vulnerable data
  subjects · innovative use / new technology · prevents a service/contract.
- **Heuristic:** ≥2 criteria → DPIA required · 1 → likely · 0 → not indicated
  (a single strong criterion can still require one).
- **Sources:** https://datatilsynet.no/ · WP248 rev.01 (edpb.europa.eu)
- **Licence:** Norwegian public-sector information (reuse permitted with attribution).
