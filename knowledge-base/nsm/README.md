# NSM Grunnprinsipper for IKT-sikkerhet

**NSM basic principles for ICT security v2.1** — 21 principles / 118 measures
across four categories (IDENTIFY · PROTECT & MAINTAIN · DETECT · RESPOND &
RECOVER), with an official ISO/IEC 27002:2022 crosswalk. The ROS generator
emits risks _per principle_, never ad hoc.
